# Efrén De Dios Miramontes

Soy estudiante de ingeniería, desarrollador de software y artista. Me gusta aprender construyendo: convertir una idea en una aplicación, una API o una herramienta que se pueda probar y mejorar.

## Qué hago

- Desarrollo aplicaciones Android con **Kotlin** y **Jetpack Compose**.
- Creo APIs y servicios backend con **Java**, **Spring Boot**, **Hibernate** y **PostgreSQL**.
- Trabajo en proyectos web con **HTML**, **CSS**, **JavaScript** y **PHP**.
- Uso **Supabase** para autenticación y datos en proyectos móviles.
- Exploro la intersección entre tecnología y creatividad, especialmente en proyectos de música y bienestar emocional.

## Cómo trabajo

Aprendo haciendo proyectos de distintos tamaños: desde ejercicios y CRUDs hasta aplicaciones móviles con varias partes conectadas. Me interesa entender cómo funciona cada herramienta y aplicarla para resolver un problema concreto, sin dejar de lado el diseño y la experiencia de uso.
